# Sistema de Gestión de Jugadores de Tenis

## Descripción

Programa desarrollado en C++ para administrar jugadores de tenis mediante consola.

## Datos registrados

- Nombre
- Categoría
- Edad
- Partidos ganados
- Ranking

## Funciones

- Registrar jugadores
- Mostrar jugadores
- Buscar jugadores
- Reporte general
- Cálculo de nivel deportivo

## Componente creativo

El sistema calcula el nivel del jugador según sus partidos ganados:

10 o más victorias:
Profesional

5 a 9 victorias:
Intermedio

Menos de 5:
Principiante
